## 1. 排版优化（参照聚宽/同花顺 iFinD 等专业级）

### 1.1 当前问题

| 页面 | 问题 |
|---|---|
| 板块温度视图 | 排行条形图固定 640px 单列，493 板块只能看 Top 80；无行业分组；无热力图矩阵 |
| 情绪视图 | 五联面板纵向堆叠，屏幕利用率低；无信息聚合卡片 |
| /mkt 页 | iframe 嵌套，头栏信息少；无快捷导航 |
| 管理/生成页 | 功能正常但偏"开发者风格"，信息密度和视觉层次可提升 |

### 1.2 优化方案

**A. 板块温度视图重构（sector_viewer.py）**

参照聚宽行业热力图 + iFinD 板块排名：

| 区域 | 当前 | 优化 |
|---|---|---|
| 顶部信息卡 | 无 | 当日摘要：最热/最冷板块 Top5 卡片 + 大盘情绪 + 上涨板块占比 |
| 排行榜 | 单列条形 80 个 | **热力图矩阵**（按行业分组排列，颜色=温度，大小=rank）+ 搜索定位 |
| 曲线区 | 固定单板块 | 支持**多板块叠加对比**（≤5 条曲线，点击热力图块 toggle） |
| 侧栏 | 分量明细 | 增加**近5日温度变化趋势**迷你图 + 分量明细 |
| 布局 | 左右 46/53 固定 | 上（信息卡+热力图 60%）/ 下（曲线+分量 40%）两行 |

**B. 情绪视图优化（viewer.py）**

- 顶部增加**信息聚合条**：当日情绪分大字 + 阶段 + 环比 + 极值区间标注
- 五联面板改两列布局（K线+成交量 左列，情绪分+涨停+炸板率 右列），屏幕利用率翻倍
- 图例和轴标签优化：中文字体、数值格式化

**C. /mkt 页优化**

- 头栏改为数据面板：数据日期 + 规则名 + 发布时间 + 类型切换 + 全屏按钮
- iframe 高度自适应（去掉固定 900px，用 postMessage 或 CSS）

### 1.3 实现约束

- 保持自包含 HTML（不依赖 CDN/外部资源）
- ECharts 单库（不引入其他图表库）
- 昼夜双主题保持
- 文件体积控制：板块温度 ≤5MB，情绪 ≤3MB

## 3. 数据补全（情绪图附图数据范围）

### 3.1 问题定位

| 附图 | 当前数据范围 | 根因 |
|---|---|---|
| 涨停/跌停家数 | 2020-01-02 起 ✓ | tushare 回补完成 |
| 炸板率 | 2020-01-02 起 ✓ | 同上 |
| **涨跌家数（up/down）** | **仅 4 行（近几天）** | 乐咕 clist 快照只有当日，无历史 |
| 资金流 | 2026-04 起 ✓ | 东财接口约 120 日 |

另外：`viewer.py` 的 `years` 参数（生成规则中默认 2 年）会**截断所有面板数据**到近 2 年——这是用户看到的"只有 2 年"的直接原因。

### 3.2 修复方案

**A. years 参数只截断情绪分曲线，不截断附图**
- `build_payload` 改为：情绪分/K线按 years 截断；涨停/涨跌家数/炸板率全量嵌入
- 附图数据量很小（1643 日 × 3 列 ≈ 50KB），不影响文件大小

**B. 涨跌家数历史补全（从指数日线推算）**
- 上证指数 + 深证综指的涨跌家数可以从 `daily_basic`（tushare，5100 积分已解锁）拉取：
  - `daily_basic` 每日全市场（~5000 股），有 `pct_chg` → 统计 >0 / <0 家数
  - 或用 `index_daily_all`（全部指数日线含涨跌家数字段）
- 回补范围：2018-01-01 起（与指数日线一致）
- 每日增量：tushare `daily_basic` 一次调用
- 写入 `mood_raw.up_count / down_count`

**C. 附图面板独立年限控制**
- viewer.py 增加参数 `sub_years`（附图年限，默认不限），允许用户选择性截断

## 4. 阶段拆分与验收

### S2.1-A 排版优化（执行稿 · 已确认）

**范围：信息聚合卡 + 两行布局 + 多板块对比（不做热力图，留 2.2）**

**sector_viewer 重构（四区 → 两行）**
- 上行 40%（信息聚合层）：
  · 左：当日摘要卡——最热Top5 / 最冷Top5 迷你卡片（板块名+温度+色块），点击可跳曲线
  · 右：大盘情绪对照——大字分数 + 阶段 + 近5日迷你走势
- 下行 60%（分析层，左右分栏）：
  · 左（60%）：温度排行条形图（保持现有交互）+ 搜索/最热/最冷
  · 右（40%）：多板块温度曲线叠加（≤5条，不同色系，点击排行或信息卡 toggle）+ 侧栏分量明细

**viewer（情绪视图）优化**
- 顶部增加信息聚合条：当日情绪分大字(+阶段+环比) / V1对照 / 极值标注
- 五联面板改两列：左列(K线+成交量) / 右列(情绪分+涨停+炸板率)，首屏利用率翻倍
- 轴标签/图例中文化

**/mkt 页优化**
- 头栏数据面板化：数据日期+规则名+发布时间+类型切换+全屏按钮
- iframe 高度自适应（CSS 100vh 替代固定 900px）

**验收**：首屏可见面板数翻倍；多板块曲线 ≤5 条叠加正常（点击 toggle 添加/移除）；文件大小 ≤5MB

### S2.1-B 数据补全（🟡 进行中 2026-10-16 · 执行稿）

**问题 1：years 参数截断附图**
- 根因：`viewer.py` 的 `build_payload(cfg, years)` 用同一个 cutoff 截断了 `df`（指数K线）、`comp`（情绪分）、以及附图数据（zt/dt/zb/up/down/mkt）
- 修复：**只对指数K线与情绪分曲线应用 years 截断**；涨停/涨跌家数/炸板率/接力率全量嵌入（数据量 ~1643 日 × 5 列 ≈ 80KB，不影响文件大小）
- 附图面板的 dataZoom 独立（可缩放到全历史）

**问题 2：涨跌家数（up/down_count）无历史**
- 现状：仅 4 行（乐咕快照，无历史源）
- 修复方案：tushare `daily_basic`（5100 积分已解锁，每日全市场 ~5000 股）
  - `daily_basic` 返回字段含 `pct_chg`（当日涨跌幅）→ 统计 >0（上涨）/ <0（下跌）家数
  - 每次调用一天全量，按日循环回补 2018-01-02 起
  - 注意：daily_basic 覆盖沪深A股，不含北交所（影响极小）
  - 写入 `mood_raw.up_count / down_count`
- 回补量：~1750 交易日 × 1 请求 × 0.6s ≈ 17 分钟（后台跑）
- 日常增量：fetch_daily 主链自动追加当日（1 请求/日，+0.6s）

**问题 3：/mkt 附图年限视觉不连续**
- viewer.py 的 dataZoom slider 默认 start 位置由情绪分截断决定——附图全量后 slider 需独立调整
- 修复：附图 slider 默认展示近 2 年（与主图一致），但可拖到全历史

**实现清单**
1. `core/viewer.py`：build_payload 拆分截断逻辑（K线/情绪分截断，附图全量）；附图 dataZoom 独立
2. `core/fetch_daily.py`：新增 `fetch_breadth_from_tushare(start)` 函数（daily_basic → 涨跌家数）
3. `core/fetch_daily.py`：主链增量调用（当日 1 请求）
4. 独立回补命令：`python fetch_daily.py --breadth-backfill [START]`（默认 20180102）
5. viewer 附图确认修复效果

**验收**
- 附图（涨停/涨跌家数/炸板率）数据范围 ≥ 2018-01-02
- viewer 生成文件大小增量 < 200KB
- 主图（K线/情绪分）仍按 years 参数截断
- 附图 slider 可拖到全历史
