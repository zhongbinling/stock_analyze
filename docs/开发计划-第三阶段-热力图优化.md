## S3-A 热力图核心体验优化（P0，执行稿 · 2026-10-17 细化，已确认）

**改动文件**：仅 `core/sector_viewer.py`（前端优化，不动后端数据层）

### 1. 分段对称色阶（visualMap pieces）

替换现有线性 continuous visualMap 为分段 pieces：
```javascript
visualMap: {
  type: 'piecewise',
  pieces: [
    { gt: 80,  label: '极热', color: '#b71c1c' },
    { gt: 50,  lte: 80, label: '强热', color: '#e34948' },
    { gt: 20,  lte: 50, label: '偏热', color: '#ef9a9a' },
    { gt: -20, lte: 20, label: '中性', color: '#e1e0d9' },
    { gt: -50, lte: -20, label: '偏冷', color: '#90caf9' },
    { gt: -80, lte: -50, label: '强冷', color: '#42a5f5' },
    { lte: -80, label: '极冷', color: '#1565c0' },
  ],
  orient: 'horizontal', left: 'center', bottom: 0,
  textStyle: { fontSize: 9, color: '#898781' },
  formatter: v => `${v} ${labelOf(v)}`,
}
```
- 色标位于热力图底部，水平排列，每段标注「极冷/偏冷/中性/偏热/极热」
- 白色（中性）为 0 值基准色，±20~50 用中等饱和度区分，|>80| 用深色

### 2. 行业命名规范（Y 轴标签）

- SW1 行已去除 `SW1_` 前缀（sector_viewer.py 已有，确认无回归）

- Y 轴板块名字号 8px，组名 10px 加粗

### 3. Tooltip 信息扩容

当前：`板块名 / 日期 / 温度`
扩展为：
```

2026-07-29

核心驱动：量能×方向 -50 · RSI 22
```

- `D.sw1_groups` 反查申万归属
- 分位 `D.rank` 如无则省略

### 4. 排名语义修正

- 信息卡片：`排名100%` → `分位 100%`
- 排行图 yAxis 标签的 `▶` 前缀保持

### 5. 热力图↔分量图联动

- **Hover 联动**：`rankC.on('mouseover')` 获取 hover 的板块 → 调 `drawSide()` 切换分量明细
- **Click 联动**：现有 toggleSel 保持（点击 → 加入/移出对比列表）

**验收**

### 2. 十字高亮联动

ECharts heatmap 无内置行列高亮。实现方案：
- 在 `drawHeatmap` 的 `emphasis` 基础上，利用 `markLine` 或 `graphic` 实现行/列高亮
- 更简单方案：用 ECharts `axisPointer` 配置：
```javascript
tooltip: { trigger: 'item', axisPointer: { type: 'cross', label: { backgroundColor: '#616771' } } }
```
- 热力图 hover 时整列日期自动高亮（axisPointer cross）
- 整行高亮（当前行业）用 `emphasis` 已有（hover cell 高亮该 cell），增强为用 `series.itemStyle` + `selectedMode: 'single'`

实际可行方案：用 axisPointer 的 cross 类型做列高亮，行高亮不做（ECharts heatmap 限制）。列高亮即可满足需求。

### 3. 时间快捷按钮

在 slider 下方增加：
```html
<div class="time-quick">
  <button onclick="hmZoom(5)">近5日</button>
  <button onclick="hmZoom(20)">近20日</button>
  <button class="active" onclick="hmZoom(60)">近60日</button>
  <button onclick="hmZoom(120)">近120日</button>
  <button onclick="hmZoom(0)">全部</button>
</div>
```
```javascript
function hmZoom(days) {
  if (!days) chart dispatch dataZoom 0~100
  else chart dispatch dataZoom (100-days/N*100)~100
}
```

### 4. 申万一级行业筛选

swFilter 下拉选中某个一级行业后：
- 热力图 Y 轴只显示该组板块
- 排行图只显示该组板块
- 清除选择恢复全量

### 5. 排序模式

sortMode 下拉改变排行/热力图数据排序：
- `score`：当日温度（默认，现有）
- `chg`：今日温度变化（今日 - 昨日差值排序）
- `ext`：区间极值（区间内最高温或最低温排序）

**验收**
1. 顶部两行功能分区清晰（功能栏+概览栏）
2. 时间快捷按钮切换正常（5/20/60/120/全部）
3. 十字高亮（列高亮）悬停可见
4. 申万一级筛选后 Y 轴只显示该组
5. 排序模式切换后排行/热力图顺序变化
6. 零 JS 错误

## S3-E 二级行业分组（✅ 已完成 2026-10-17 · 执行稿）

**目标**：完善申万二级分类数据 + 热力图层级切换

### 1. 申万二级数据获取（扩展 core/sw1_map.py → sw_map.py）
- tushare `index_classify(level='L2', src='SW2021')` + `index_member`
- 成分股投票法 → 东财行业名 → BK码 → 申万二级
- 写入 `sw2_map(bk_code, bk_name, sw1_name, sw2_name)`

### 2. SW2 聚合温度计算（扩展 core/sector.py）
- `_calc_sw2()`：按 sw2_map 分组，计算成分板块平均温度
- 写入 sector_scores（code = SW2_+名称），与 SW1_ 共存

### 3. 热力图层级切换（sector_viewer.py）
- `[一级] [二级] [三级]` 按钮组
- 一级：只显示 SW1_ 行（~28 个）
- 二级：只显示 SW2_ 行（~100+ 个），SW L1 做组头
- 三级：全部 BK_ 行（~493 个，现有）
- build_payload 增加 sw2_groups + level_data

### 4. swFilter 与层级联动
- 一级模式 → swFilter 填充 SW L1 列表
- 二级 → 填充 SW L2 列表
- 三级 → 恢复 SW L1 或空

### 5. 排行图同步切换
- 层级切换后排行图显示对应聚合温度排名

**验收**
- sw2_map ≥ 100 个二级映射
- sector_scores 含 SW2_ 行
- 热力图三级切换正常（28/100+/493 行）
- swFilter 与层级联动
- 零 JS 错误
