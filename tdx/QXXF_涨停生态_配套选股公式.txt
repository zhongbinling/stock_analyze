{================================================================}
{ 涨停生态 · 配套条件选股公式  (配合QXXF2使用)                     }
{----------------------------------------------------------------}
{ 背景: 通达信公式无法在指标里直接统计全市场涨停家数/连板高度/      }
{       炸板率(横截面数据), 赚钱效应维度用"选股入板块"落地:         }
{ 每日收盘后跑条件选股 → 结果"加入板块" → 维护5个自定义板块:        }
{   ZT涨停板 / DT跌停板 / ZB炸板 / LB连板 / YZT昨日涨停             }
{ 用途:                                                            }
{   ① 打开各板块的板块指数, 挂QXXF2公式 = 各自的情绪温度           }
{     (尤其"昨日涨停"板块指数的QXXF2分 = 赚钱效应温度)             }
{   ② 板块内股票数 = 家数, 人工/看盘面读数                        }
{   ③ 精确统计与历史回看请用 Python 版(见 core/目录)              }
{----------------------------------------------------------------}
{ 建公式: Ctrl+F → 条件选股 → 新建, 下面5个公式分别单独建立,       }
{         选股范围选"沪深A股"(含北交所则口径覆盖北交所)             }
{ 老版本无ZTPRICE/DTPRICE函数时, 用文末近似替代                     }
{================================================================}

{================ 公式1: XG_ZT 涨停板 =================}
{按板块自动适配涨跌幅: 北交所30% 创业板/科创板20% ST 5% 主板10%}
BL:=IF(CODELIKE('43') OR CODELIKE('83') OR CODELIKE('87') OR CODELIKE('92'),0.3,IF(INBLOCK('创业板') OR INBLOCK('科创板'),0.2,IF(NAMELIKE('ST') OR NAMELIKE('*'),0.05,0.1)));
XG: CLOSE>=ZTPRICE(REF(CLOSE,1),BL);

{================ 公式2: XG_DT 跌停板 =================}
BL:=IF(CODELIKE('43') OR CODELIKE('83') OR CODELIKE('87') OR CODELIKE('92'),0.3,IF(INBLOCK('创业板') OR INBLOCK('科创板'),0.2,IF(NAMELIKE('ST') OR NAMELIKE('*'),0.05,0.1)));
XG: CLOSE<=DTPRICE(REF(CLOSE,1),BL);

{================ 公式3: XG_ZB 炸板 ===================}
{盘中触及涨停价但收盘未封住}
BL:=IF(CODELIKE('43') OR CODELIKE('83') OR CODELIKE('87') OR CODELIKE('92'),0.3,IF(INBLOCK('创业板') OR INBLOCK('科创板'),0.2,IF(NAMELIKE('ST') OR NAMELIKE('*'),0.05,0.1)));
ZTJ:=ZTPRICE(REF(CLOSE,1),BL);
XG: HIGH>=ZTJ-0.001 AND CLOSE<ZTJ-0.001;

{================ 公式4: XG_LB K连板及以上 =============}
{K=连板天数, 需要几连板就改K后另存(如XG_LB3/XG_LB5); }
{连板高度=由高到低依次跑(K=8,7,6...), 有结果的最高K即高度}
BL:=IF(CODELIKE('43') OR CODELIKE('83') OR CODELIKE('87') OR CODELIKE('92'),0.3,IF(INBLOCK('创业板') OR INBLOCK('科创板'),0.2,IF(NAMELIKE('ST') OR NAMELIKE('*'),0.05,0.1)));
K:=2;
XG: EVERY(CLOSE>=ZTPRICE(REF(CLOSE,1),BL),K);

{================ 公式5: XG_YZT 昨日涨停 ===============}
{昨日涨停股今日表现观察池(赚钱效应核心指标)}
BL:=IF(CODELIKE('43') OR CODELIKE('83') OR CODELIKE('87') OR CODELIKE('92'),0.3,IF(INBLOCK('创业板') OR INBLOCK('科创板'),0.2,IF(NAMELIKE('ST') OR NAMELIKE('*'),0.05,0.1)));
XG: REF(CLOSE>=ZTPRICE(REF(CLOSE,1),BL),1);

{================================================================}
{ 老版本无ZTPRICE/DTPRICE时的近似替代(容差法, 极低价股偶有误差):   }
{   涨停: CLOSE>=REF(CLOSE,1)*(1+BL)-0.005 AND CLOSE=HIGH;         }
{   跌停: CLOSE<=REF(CLOSE,1)*(1-BL)+0.005 AND CLOSE=LOW;          }
{----------------------------------------------------------------}
{ 炸板率 = 炸板数 / (涨停数+炸板数), 由板块股票数手工计算           }
{ (ZB板块家数 / (ZT板块家数+ZB板块家数))                            }
{================================================================}
