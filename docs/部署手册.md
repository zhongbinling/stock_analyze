# 部署手册（草稿 · S4 完成三平台全量内容）

> 当前状态：S0 骨架。S4 交付三平台一键部署脚本（`scripts/deploy_win.bat` / `deploy_mac.sh` / `deploy_linux.sh`）与服务自启配置后，本手册补全为正式版。

## 通用（三平台一致的内核流程）

```bash
# 1) Python 3.10+ 环境后:
git clone <仓库地址> stock_analyze && cd stock_analyze
pip install -r requirements.txt

# 2) 数据库迁移(首次/每次升级后)
python -m flask --app "server:create_app()" db upgrade

# 3) 创建超级管理员(首次; 交互输入密码, 也可管道)
python -m server.bootstrap --username admin
#    自动化: printf "你的密码
你的密码
" | python -m server.bootstrap --username admin

# 4) 启动服务
python -m server            # http://127.0.0.1:8501  (配置: config/server.yaml)
#    管理端: /admin/login 用超管登录

# 5) 评分引擎初始化行情数据(首次, 8~12分钟)
cd core && python fetch_daily.py
```

## Windows（S4 交付）

- 服务脚本：`scripts\service.bat start|stop|status|restart`（pythonw 后台 + PID 文件）
- 一键部署：`scripts\deploy_win.bat`（venv + 依赖 + 迁移 + 自启注册 + 启动）
- 开机自启：任务计划程序注册（脚本附带说明）

## macOS（S4 交付）

- `scripts/service.sh start|stop|status|restart`
- 一键部署：`scripts/deploy_mac.sh`；自启：launchd plist 模板

## Linux（S4 交付）

- `scripts/service.sh start|stop|status|restart`
- 一键部署：`scripts/deploy_linux.sh`；自启：systemd 单元模板
