## D1 · 数据补全管理（数据管理页新增「数据补全」区）

### D1-1 基础数据清单与状态（含用户要求的时间区间/数据量/完成度）

- **数据资产注册表**（代码内清单或 app.db `data_assets` 表）：每个数据集登记
  表名/来源/日期列/依赖/回补函数/说明——数据管理页"数据集一览"升级为从此渲染
- 每行状态：时间区间、行数、**完成度预估%**（以交易日历为基准：
  `distinct 日期数 ÷ 区间内交易日数`；板块类数据再乘板块覆盖率）、缺口明细
  （缺哪些交易日，悬停/展开列出，如"2026-03-14 缺"）
- 行业分级数据专项：sw1_map(L1)/sw2_map(L2) 状态 + **新增 sw3_map(L3) 构建**
  （tushare `index_classify level=L3` + `index_member` 成分投票，复用 build_sw2 模式）；
  L1/L2/L3 层级树可视化（板块数/覆盖 BK 数）

### D1-2 补全执行

- 勾选数据集 + 起始日 → 入队（复用 jobs 单工作线程，与更新/备份互斥）
- 统一入口：`core/fetch_daily.py backfill --dataset <name> --start YYYYMMDD`
  （封装既有 backfill_tushare / backfill_zt_est / breadth 回补 / 新增 sector_daily
  历史回补与 sw3_map 构建）
- 补全前自动快照（复用 backup：tag=pre-backfill）

### D1-3 补全日志与异常定位

- 新表 `data_backfill_log(id, dataset, date_from, date_to, rows_written,
  rows_skipped, status, started_at, finished_at, error)`；**按 (dataset, 日期) 可查**
- 数据异常时反查：某日某表数据可疑 → 查该 (dataset, date) 的写入记录
  （哪个任务/何时/写了多少行）→ 支撑"清理后重新补全"
- 页面：补全历史表 + 按数据集过滤 + 点数据集看逐日写入明细

## D2 · 手动更新与评分数据增强

### D2-1 更新任务透明化

- 现有手动更新保留；任务链分步展示：抓取(fetch) → 大盘评分(score) → 板块温度
  (sector calc 含 SW1/SW2 聚合) 各步耗时/返回码/影响行数，日志分段折叠
- 更新历史（jobs 表）页内可下钻看完整日志（现有 jobpoll 只显当前）

### D2-2 评分数据状态卡（数据管理页新增）

- **评分类型清单**（用户要求：有哪些类型/各自区间/是否正常）：
  - 大盘情绪分（sentiment）：区间、最新日期、行数
  - 板块温度-BK 行业（493 板块）、板块温度-SW1 聚合（28）、板块温度-SW2 聚合
    （62）：各自区间/行数/最新日期
- 健康判定：`最新评分日期 == 行情最新日期`（落后即黄/红）、
  行数与板块数×交易日数比例合理性、components 覆盖天数（近窗口）
- 数据来源：market.datasets() 扩展评分数据集条目（同页同表呈现）

### D2-3 补全后联动重算

- 基础数据补全任务尾部可选"自动重算评分"（默认开）：
  `score.py` 全量 + `sector.py calc`（自动含 SW1/SW2/SW3 聚合与 pre-calc 快照）
- 页面提示链路：补全完成 → 弹出"基础数据已更新，建议重算评分"一键执行
- 保证后续视图生成（数据生成页）用到的是补全后的完整评分

## 验收（含 pytest 全绿）

1. 数据补全区：每个数据集显示区间/行数/完成度%，缺口可展开；实测能暴露上表现状缺口
2. L3 映射 ≥150 个三级、sector_scores 出现 SW3_ 行、热力图层级可切 L3（viewer 联动项另立卡）
3. 补全一个数据集：data_backfill_log 落库逐日明细；人为改坏某日数据 → 按 (dataset,date) 反查到写入记录
4. 评分状态卡：四类评分各自区间/最新/健康色；手动更新分步日志可见
5. 补全后自动重算开关生效：sentiment 与 sector_scores 最新日期 == 行情最新日期
6. pytest：完成度/缺口计算、data_backfill_log 埋点、评分状态聚合、backfill CLI 参数化、
   sw3 投票映射（临时库）、联动重算入队 —— 全绿交付
