### D1-2 补全执行（执行稿 · 2026-10-18 细化确认）

**补全数据集（`core/fetch_daily.py` BACKFILLS 注册表）**——只封装**已有**回补函数，
不新增重型抓取（板块日线/资金流/两融为增量型，置灰说明"随每日更新链积累"）：

| dataset | 动作 | 目标表(增量度量) |
|---|---|---|
| zt_est | 涨停家数估算回补(2012-2019) | mood_raw.zt |
| zt_ts | 涨停结构 tushare 回补(2020起) | mood_raw.zt + sector_pool_stat |
| breadth | 涨跌家数 tushare 回补(2018起) | mood_raw.up |
| calendar | 交易日历刷新 | calendar |

**`run_backfill(dataset, start)`**：
- 前置 `backup.snapshot("sentiment", "pre-backfill")`（异常不阻断）
- **增量度量**：执行前后按日计数目标表（`WHERE col IS NOT NULL`）→ 逐日差集
  `{date, rows}`——不改既有回补函数内部，天然适配任意目标
- 幂等：既有函数本身跳过已有日期
- CLI：`python fetch_daily.py --backfill <dataset> --start YYYYMMDD`，
  只跑补全不走常规抓取链；末行输出 `@@BACKFILL@@ {json}` 供服务解析

**服务端（jobs.task_backfill）**：subprocess 执行（与 update 同模式，日志流式入 job），
解析结果 JSON → 落 `DataBackfillLog`；BACKFILL_DATASETS 清单在 jobs 模块（路由复用校验）

## D1-5 历史覆盖扩展（执行稿 · 2026-10-18 细化确认）

**根因实证**：`sectors.py HIST_BEG="20180101"` 只是**当时的选择**（注释"温度计窗口
绰绰有余"），非源限制——`sector_kline(beg=...)` 直通东财，S2.2 已证 2018 可得。
**探测结论（2026-10-18）**：push2his 全系域名（含编号镜像）当前被断（今日大量回补
触发临时限制，腾讯源正常），无法即时验证 2012 下限——**探测并入回补**：第一个
老板块的实际返回最早日期即结论；给不出 2012 的板块照常写入其可得段（新板块本来就晚）。

**物理边界（2026-10-18 用户确认为数据更新规则）**：250 日滚动窗口 →
sector_daily 即便 2012-01 起，板块温度最早 **2013-01**（与大盘情绪分 2013-05 起
同理）；**2012 年只看情绪曲线，热力图自 2013 起**——已固化至 `docs/数据说明.md` §5。

**实现（本轮）**：
- `fetch_daily.backfill_sector_history(start=20120101)`：逐启用板块 `beg=start` 拉
  K 线 `_upsert_bars`（幂等，只新增更早行）；板块现有最早日 ≤ start 则跳过请求；
  熔断对齐 `backfill_history`（连续 10 次失败）+ 网络快速失败（err_streak≥5）；
  `[i/N]` 进度输出（兼容 D1-4 运行态解析）
- BACKFILLS 注册 `sector_history`（默认起始 20120101）→ 走 D1-2 通道 +
  D2-3 联动重算；页面下拉新增该项
- **C 口径落地**：早期无板块涨停聚合/涨跌家数 → 引擎缺失归一化容忍
  （zt 组 ~10% 权重），温度由量价分量主导；up/down_count 历史不可得（东财快照
  采集制），早期 ud_ratio 分量缺失同理——生成页/文档注明
- 视图侧：热力图要看到 2013+，生成规则 `years` 调大（≥6）即可，无需改代码

**执行窗口**：push2his 恢复后页面/CLI 触发 `sector_history`（预计 493 板块 ×
0.25s ≈ 5-10 分钟）→ 自动重算 → 验证 sector_scores 最早日前移至 ~2013-01。
**B 备选保留**：若东财历史下限不足，转 tushare `sw_daily` 申万指数日线（分层并存）。

## D1-6 申万层级历史数据工程（tushare 5100 自建方案 · 2026-10-18 服务商方案+接口实测确认）

> 结论：**无需外购**——5100 积分已解锁全部所需接口；板块级指标 =
> 「个股原始数据 × 申万历史成分还原 × 按日聚合」。产出为**申万 L1/L2(/L3) 层级**底座，
> 东财 BK 行维持 D1-5 通道不变。

**接口实测（2026-10-18，修正服务商方案三处）**：
| 接口 | 实测 | 结论 |
|---|---|---|
| index_member | 含 `in_date/out_date/is_new` **区间记录** | 成分还原无需逐日重放——直接 `in_date≤d<(out_date\|\|∞)` 区间查询，比服务商代码更简 |
| sw_daily | 2010-2012 段有数据；单次 4000 行上限 | B1 申万指数日线全历史可得，按年分段拉 |
| moneyflow | 2012-05-04 有 2275 行 | A2 资金流全历史可得 |
| limit_list_d | 2019-12 有 / 2015·2012·2010 **空** | 真实边界≈2019 末（修正"全历史"假设）；A3/A4 早期仍需 daily 阈值估算（复用 `_est_zt_count`，升级为按成分股聚合到板块级） |
