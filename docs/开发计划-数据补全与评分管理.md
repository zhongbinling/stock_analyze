## D1 · 数据补全管理（数据管理页新增「数据补全」区）

### D1-1 基础数据清单与状态（执行稿 · 2026-10-18 细化确认）

**目标**：每个基础数据集显示 时间区间 / 数据量 / **完成度预估%** / 缺口明细——把"资金流仅半年、
板块日线 2018 起"这类缺口系统化暴露（实测基线见文首盘点表）

**资产注册表（代码级，`server/market.py` ASSET_SPECS）**
- 本期代码内清单（app.db `data_assets` 表留待第四阶段运维动态注册时再迁）
- 登记项：code / 名称 / 表 / 日期口径(where) / 来源 / 陈旧阈值 / 说明
- 覆盖：指数日线、涨停池、涨跌家数、板块日线、板块涨停聚合、板块资金流、两融、
  交易日历、板块清单、sw1_map / sw2_map（sw3_map 表存在则显示，构建归 L3 专项）

**完成度与缺口（`datasets()` 升级为注册表驱动）**
- 交易日基准：优先 `calendar(is_open=1)`（cal_date 归一 YYYY-MM-DD）；日历缺失/不覆盖时
  回退 index_daily 主力指数日期
- `完成度% = distinct日期数 ÷ 区间内交易日数`（钳 0~100）；`缺口 = 基准日 − 已有日`
  （返回缺失数 + 最近缺失明细，页面 title 悬停全览）
- **修正决策①**：不乘"板块覆盖率"——板块清单随时间变动（退市/新增），乘上去会失真；
  板块数单独成列展示
- 健康规则保留现有（陈旧天数阈值），新增：**有缺失交易日（完成度<100）warn、<80 bad**；
  涨停池旧"缺失>3 天"口径被新规则覆盖（更严格）
- 评分数据仍在 D2-2 评分卡，不混入

**页面（data.html 数据集表）**
- 列扩展：数据集/来源/行数/**板块数**/区间/**完成度**/**缺口**/健康/说明
- 完成度着色（100 绿 / ≥95 黄 / <95 红），缺口格显示"缺 N 天"+title 列出明细

**测试（tests/test_market_assets.py，专用真实感夹具）**
- 夹具：calendar 仅工作日开市；index_daily 挖 2 个缺口、sector_daily 挖 3 个 →
  完成度/缺口列表精确断言；多余周末行钳 100；删 calendar → 回退基准；
  sw1/sw2 行数与说明；sw3 未构建提示行；datasets() 兼容字段
- 全量 `python -m pytest tests -q` 全绿

### D1-2 补全执行（执行稿 · 2026-10-18 细化确认）

**补全数据集（`core/fetch_daily.py` BACKFILLS 注册表）**——只封装**已有**回补函数，
不新增重型抓取（板块日线/资金流/两融为增量型，置灰说明"随每日更新链积累"）：

| dataset | 动作 | 目标表(增量度量) |
|---|---|---|
| zt_est | 涨停家数估算回补(2012-2019) | mood_raw.zt |
| zt_ts | 涨停结构 tushare 回补(2020起) | mood_raw.zt + sector_pool_stat |
| breadth | 涨跌家数 tushare 回补(2018起) | mood_raw.up |
| calendar | 交易日历刷新 | calendar |

**`run_backfill(dataset, start)`**：
- 前置 `backup.snapshot("sentiment", "pre-backfill")`（异常不阻断）
- **增量度量**：执行前后按日计数目标表（`WHERE col IS NOT NULL`）→ 逐日差集
  `{date, rows}`——不改既有回补函数内部，天然适配任意目标
- 幂等：既有函数本身跳过已有日期
- CLI：`python fetch_daily.py --backfill <dataset> --start YYYYMMDD`，
  只跑补全不走常规抓取链；末行输出 `@@BACKFILL@@ {json}` 供服务解析

**服务端（jobs.task_backfill）**：subprocess 执行（与 update 同模式，日志流式入 job），
解析结果 JSON → 落 `DataBackfillLog`；BACKFILL_DATASETS 清单在 jobs 模块（路由复用校验）

### D1-3 补全日志与异常定位（执行稿）

**新表 `data_backfill_log`**（迁移接 a7f3c2d81e94）：
`id / dataset / label / date_from / date_to / rows_written / status / trigger /
days_json([{date,rows}…]) / duration_s / error / started_at / finished_at`

**API**：
- `POST /admin/api/backfill/run {dataset, start}` → 校验+入队（audit）
- `GET /admin/api/backfill/logs?dataset=&date=` → 最近50条；**date 参数=按(数据集×日期)
  反查**（days_json 含该日的记录）——数据异常定位入口

**页面（data.html「数据补全」卡）**：数据集下拉+起始日+[开始补全]（复用 jobpoll 运行态）；
补全历史表（时间/数据集/区间/写入行数/状态/触发，title 逐日明细）；
**按日期反查**输入框 → 过滤出该日被写过的记录

**验收与测试**：core 侧 run_backfill（快照前置/逐日增量/未知数据集/结果JSON）；
server 侧 task 落库（成功/失败/无结果行）、API 校验与入队、logs 列表与日期反查；
`pytest tests -q` 全绿 + 真实库 calendar 冒烟 + app.db 迁移执行

### D2-2 评分数据状态卡（执行稿 · 2026-10-18 细化确认）

**目标**：评分数据是关键数据——数据管理页清晰呈现"有哪些类型/各自区间/是否正常"

**数据层（server/market.py 新增 `score_datasets()`）**：

| code | 类型 | 口径 |
|---|---|---|
| score:sentiment | 大盘情绪分 | sentiment 表 |
| score:bk | 板块温度·行业板块 | sector_scores `code LIKE 'BK%'` |
| score:sw1 | 板块温度·申万一级聚合 | `SW1_%` |
| score:sw2 | 板块温度·申万二级聚合 | `SW2_%` |

- 每条返回：行数 / 区间(first~last) / 板块数(distinct code) / 覆盖交易日数(distinct date) /
  最新日期 / 健康 / 说明
- **健康基准 = 行情最新日期**（index_daily 主力指数 MAX(date)，非自然日）：
  `ok`＝评分最新==行情最新；`warn`＝落后（说明标注"落后行情 N 天"）；`bad`＝无数据
- BK 条目说明附**分量明细覆盖至 X**（components 最近非空日期，引擎仅保留 260 日）
- `datasets()` 移除 sentiment 与 sector_scores 两行（评分数据归入本卡，不再与基础数据混排）

**接口/页面**：
- `/admin/api/datasets` 响应增加 `scores` 字段（向后兼容，旧键不动）
- data.html 新增「评分数据状态」卡：类型/区间/行数/板块数/最新/健康/说明，
  健康色沿用现有 ok/bad 样式；刷新按钮联动

**测试（tests/test_market_scores.py + conftest 扩展）**：
- conftest：fixture_db 补 index_daily 表（含主力指数行）；新增共享 `server_app` 夹具
  （临时配置+app.db+登录管理员，test_server_backup 重构复用）
- market 单测：四类条目字段正确 / 健康三态（追平=ok、落后=warn、无数据=bad）/
  BK 分量覆盖说明
- API 测试：/admin/api/datasets 返回 scores 且四条
- 全量 `python -m pytest tests -q` 全绿

### D2-3 补全后联动重算

- 基础数据补全任务尾部可选"自动重算评分"（默认开）：
  `score.py` 全量 + `sector.py calc`（自动含 SW1/SW2/SW3 聚合与 pre-calc 快照）
- 页面提示链路：补全完成 → 弹出"基础数据已更新，建议重算评分"一键执行
- 保证后续视图生成（数据生成页）用到的是补全后的完整评分

1. 数据补全区：每个数据集显示区间/行数/完成度%，缺口可展开；实测能暴露上表现状缺口

4. 评分状态卡：四类评分各自区间/最新/健康色；手动更新分步日志可见
5. 补全后自动重算开关生效：sentiment 与 sector_scores 最新日期 == 行情最新日期
6. pytest：完成度/缺口计算、data_backfill_log 埋点、评分状态聚合、backfill CLI 参数化、
   sw3 投票映射（临时库）、联动重算入队 —— 全绿交付
