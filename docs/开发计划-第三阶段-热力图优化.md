## S3-C 业务差异化（P1，执行稿 · 2026-10-18 细化）

**改动文件**：仅 `core/sector_viewer.py`（纯前端规则引擎，不动后端/数据层）
**前置数据**：`D.mat`（全区间温度矩阵，算 5 日变化）、`D.comp`（近 5 日分量明细，算背离）均已存在

### 1. 温度语义引擎 `semanticOf(v, d5)` → 一句话定性

d5 = 当前温度 − 5 交易日前温度（从 mat 取，hover 日期感知）。规则按优先级：

| 条件 | 语义短语 |
|---|---|
| v≥60 且 d5≤−10 | 高位回落 · 警惕退潮 |
| v≥60 且 d5≥10 | 加速冲顶 · 情绪亢奋 |
| v≥60 | 过热区 · 谨慎追高 |
| v≥40 且 d5>0 | 强势升温 · 趋势延续 |
| v≥40 | 强势区 · 动能减弱 |
| v≥20 且 d5>5 | 升温发酵 · 关注持续性 |
| v≥20 | 温热区 · 滞涨迹象 |
| \|v\|<20，d5>5 / d5<−5 / 其余 | 中性回暖 / 中性转弱 / 中性震荡 |
| v≤−60 且 d5≤−10 | 恐慌探底 · 关注超跌反弹 |
| v≤−60 | 深度冰点 · 左侧观察区 |
| v≤−40 且 d5>5 | 冰点修复 · 反弹尝试 |
| v≤−40 | 偏冷区 · 观望为主 |
| v≤−20，d5>5 / 其余 | 低位回暖 / 持续偏冷 |

短语取「·」前半段作为卡片短标签（≤6 字）。

### 2. 量价背离检测 `divergenceOf(comps)`

用最新日分量（分位分）交叉判断，返回 `{text}` 或 null：

| 条件 | 提示 |
|---|---|
| vol_dir≤−50 且 chg≥50 | ⚠ 缩量上涨 · 量价背离 |
| fflow≤−50 且 chg≥50 | ⚠ 价涨资金流出 · 背离 |
| vol_dir≥50 且 chg≤−50 | 放量下跌 · 恐慌宣泄（可能见底信号） |
| fflow≥50 且 chg≤−50 | 价跌资金流入 · 有承接 |

阈值校准（2026-06~10 历史）：±50 为四分位语义（量能分位<25% 且涨幅分位>75%）。更松的 ±30 在全市场缩量反弹日（2026-10-16）触发 46% 沦为噪音、±45 仍有 23%；±50 异常日保留最极端一成（10%/493 板）、正常日 ~0%（9-30 为 1%、6-30 为 0%）。fflow 分量依赖 sector_fundflow 日更（当前覆盖 2026-04-17 起），数据未更新日该两条规则自动休眠。

### 3. 落点（5 处）

1. **热力图 tooltip**：现有「温度(定性)+核心驱动」下追加两行——`5日 +12`（红/蓝着色）与语义短语；触发背离时再加 ⚠ 橙色行
2. **排行图 tooltip**：温度行下加 5日Δ + 语义短语
3. **分量明细（side）**：`drawSide` 复用 `drawSideFor` 渲染（修复现有未按贡献排序的不一致）；头部加语义短语 + 背离徽标；**选中≥2 板块时顶部插入对比摘要表**（板块｜温度｜5日Δ｜短语，每板一行），下方仍显示最后选中板块的分量明细
4. **信息卡（最热/最冷 Top5）**：分位行下加短语义标签
5. **大盘情绪盒**：日期行加大盘语义短语（用 mkt 分数与 5 日变化）

### 4. 验收

1. 热力图 tooltip：任意 cell 含 5日Δ + 语义短语；背离板块出现 ⚠ 行（用实际数据找案例验证）
2. side 面板两路径（hover 联动 / 点击选中）分量均按 |贡献| 降序
3. 选中 2+ 板块时 side 顶部出现对比摘要表
4. 卡片与大盘盒显示语义标签
5. 零 JS 错误、体积 ≤6MB、既有 18 项回归测试全过
