## 1. 排版优化

### 1.1 热力图支持（sector_viewer）

**当前问题**：板块温度排行只有条形图（Top80），无法一屏总览全市场冷热分布。

**方案**：在 sector_viewer 的下行左侧区域增加**热力图矩阵模式**（与排行条形可切换）。

- 布局：按钮组 `[排行] [热力图]` 切换显示模式
- 热力图实现：ECharts `heatmap` 类型
  - X 轴：时间（近 N 日，默认 60 日，dataZoom 可缩放）
  - Y 轴：板块（按申万一级分组排列，组间加间距）
  - 颜色：温度值 → 红蓝渐变（-100 蓝 → 0 灰 → +100 红），透明度随 |score| 增强
  - Cell：显示板块温度值（悬停 tooltip 含板块名/温度/排名/阶段）
- 分组：按 sw1_map 的申万一级分组排列（同组板块相邻），组间用空行分隔
- 交互：点击 cell → toggle 该板块进右侧多板对比曲线
- 性能：60 日 × ~500 板块 = 3 万 cell，ECharts heatmap 可处理（visualMap + progressive 渲染）

### 1.2 情绪图（viewer.py）默认显示范围优化

**当前问题**：
- dataZoom 默认展示近 ~500 日（约 2 年），但用户要的是"最新一年"
- 全量打开后（拖到最左），要反复拖拽才能回到最新
- 图表面板没有标题/名字标签

**方案**：
- `start` 计算改为 `100 - (250 / D.n) * 100`（近 ~250 日 ≈ 1 年）
- 双击 dataZoom slider 或提供 `[最新1年] [全部]` 快捷按钮恢复
- 每个图表面板增加标题标签（在 grid 上方）

### 1.3 面板标题与附图可选

**当前问题**：五联面板没有面板名标签；最下面的附图（炸板率/接力率）无法选择显示/隐藏。

**方案**：
- 每个 grid 上方加 `title` 子组件（"上证指数""两市成交量""情绪分""涨停/跌停""炸板率/接力率"）
- 炸板率/接力率面板增加**显示/隐藏切换**（图例或按钮组：`[炸板率] [接力率] [涨跌家数]` 可多选）
- 附图区域支持显示多组数据（用户自选类型：炸板率/接力率/涨跌家数/连板高度/涨停占比/两市成交额/RSI/乖离率/主力净流入等——所有已有分量均可作为附图选项，用 checkbox 多选）

## 2. 数据补全

### 2.1 涨停/炸板/接力数据扩展到 2012

**当前状态**：
| 数据 | 起点 | 来源 |
|---|---|---|
| 涨跌家数 | 2018-01-02 | tushare daily ✓ |
| 涨停/跌停/炸板 | 2020-01-02 | tushare limit_list_d |
| 接力率/连板 | 2020-01-03 | 同上 |

**问题根因**：tushare `limit_list_d` 接口数据从 **2020 年 1 月**才开始，2012~2019 无数据。

**补全方案**：
- **方案 A（推荐）**：用指数日线 + 板块日线估算近似涨停家数
  - 逻辑：每日统计全市场涨幅 ≥9.8%（主板）/ ≥19.8%（创业/科创）的个股数（tushare `daily` 接口有 pct_chg）
  - 精度：估算值（不含一字板/炸板/封板率细节），但连续可用
  - 覆盖：2012-01-01 ~ 2019-12-31（daily 接口历史完整）
  - 写入 `mood_raw` 时标注来源（如新增列 `zt_source = 'est'/'tushare'`）
  - 回补量：~1950 交易日 × 1 请求 = ~22 分钟
- **方案 B（备选）**：接受 2020 起步，只在附图上显示数据可得提示
- **炸板率/接力率**：无法从日线推算（需盘中数据），只能从 2020 起

**建议**：先做方案 A 补全涨停/跌停家数到 2012；炸板率/接力率保持 2020 起（附图自动显示数据可得范围）。

### 2.2 附图面板标注数据起始日

- 每个附图面板左下角小字标注"数据起 YYYY-MM-DD"
- 窗口外区域（无数据部分）用浅灰背景区分

## 3. 操作优化

### 3.1 情绪图悬停增强

**当前问题**：鼠标悬停只显示 OHLC + 情绪分 + 涨停家数，不显示该面板对应的详细分量。

**方案**：
- 悬停时 tooltip 自动追加**当前面板相关信息**：
  - K线面板：追加"量比/乖离/位置"（来自 raw 数据）
  - 成交量面板：追加"量能分位分"（cs.vol_dir）
  - 情绪分面板：追加"V1对照/阶段/环比"
  - 涨停面板：追加"连板高度/接力率/炸板率"
  - 炸板率面板：追加"封板成功率"
- 实现：tooltip formatter 根据 `params.seriesName` 或当前 hover 的 gridIndex 动态追加

### 3.2 数据管理页手动更新响应优化

**当前问题**：点击"增量更新数据"按钮后，页面无反馈，需等 5~10 秒才看到日志——用户不知道点击是否生效。

**方案**：
- 点击后**立即**将按钮变为"⏳ 已提交，等待执行..."（disabled + 文字变更）
- 同时在日志区域显示"正在启动任务..."占位文字
- `/api/admin/jobpoll` 返回 `queued > 0` 时显示"排队中 ×N"
- 任务完成/失败后按钮恢复
- 如果 API 返回 409（队列满），立即提示
