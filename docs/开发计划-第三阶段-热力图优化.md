## 设计分析与拆解

用户提供了一份六维度完整设计文档，涵盖布局/热力图/分量图/联动/业务/视觉。核心诉求：
1. **视觉专业感**：分段色阶、行业命名规范、统一设计语言
2. **交互联动**：热力图↔分量图实时联动、十字高亮、时间轴全域同步
3. **业务差异化**：温度语义标签、量价背离、板块对比、历史快照

按落地优先级（P0→P1→P2）和实现依赖关系拆为 4 个子阶段：

---

## S3-A 热力图核心体验优化（P0，1 个会话）

**范围**：分段色阶 + 行业命名 + tooltip 扩容 + 排名语义 + 热力图↔分量图联动

### 1. 分段对称色阶
- 固定刻度：`-100, -80, -50, -20, 0, 20, 50, 80, 100`
- 颜色：深蓝 → 浅蓝 → 纯白 → 橙红 → 深红（ECharts `visualMap.pieces`）
- 色标移至热力图右上角，水平排布，标注整数刻度 + 「极冷/极热」文字
- 日常波动区间（±20~50）色阶密度最高

### 2. 行业命名规范
- 移除 `SW1_` 前缀（sector_scores 中 SW1 行的 code 以 `SW1_` 开头，Y 轴标签需去除）
- 按申万一级分组排列（已有 sw1_groups），组间加空行 + 组名标签
- Y 轴一级行业名称加粗（ECharts yAxis.axisLabel.rich text）

### 3. Tooltip 信息扩容
当前：板块名 + 日期 + 温度
扩展为：
```
防水材料（申万：建筑材料）
日期：2026-07-29
温度：-31（偏冷）· 分位 32%
核心驱动：量能×方向 -50 · RSI 22
```
- 数据来源：D.comp（最近日分量明细）+ D.sw1_groups

### 4. 排名语义修正
- 「排名100%」→「分位 100%」（rank_pct 语义化为分位数，消除歧义）
- 温度定性标签统一：极冷(<-80) / 偏冷(-80~-20) / 中性(-20~20) / 偏热(20~80) / 极热(>80)

### 5. 热力图↔分量图联动
- Hover 热力图任意行业行 → 右侧分量明细实时切换为该行业
- 点击行业行 → 固定为当前选中行业（toggle 进对比列表）
- 实现：heatmap 的 mouseover/click 事件 → `drawSide()` 传入 code index

**验收**：色阶分段正确（±20 区间色差明显）；tooltip 含申万归属+定性+分位+核心驱动；hover 行切换右侧分量；排名语义无歧义

## S3-B 布局与交互增强（P1，1 个会话）

**范围**：顶部双层功能区 + 十字高亮 + 时间快捷按钮 + 全域联动

### 1. 顶部功能区分层
拆为两行：
- **第一行（功能栏）**：标题(含日期+板块数) | 搜索框 + 一级行业筛选下拉 | 排序下拉(当日温度/区间累计/波动率) | 视图切换(热力图/榜单) | 工具组(对比/导出/深色)
- **第二行（概览栏）**：横向滚动强弱板块条(前10热+后10冷) + 放大大盘情绪卡片(数值+定性+小折线)

### 2. 十字高亮联动
- Hover 热力图 cell → 整行(行业)+整列(日期)半透明高亮
- ECharts heatmap 的 emphasis + custom overlay 实现

### 3. 时间快捷按钮
- 滑块上方：`[近5日] [近20日] [近60日] [近120日] [全部]`
- 点击同步底部滑块 + 热力图 dataZoom

### 4. 全域联动
- 拖动时间滑块 → 热力图区间更新 + 右侧分量图时间同步 + 顶部排名重算
- 右侧分量图支持独立时间缩放（dataZoom 不与左侧绑定）

**验收**：顶部两行功能分区清晰；hover 十字高亮可见；快捷时间按钮切换正常；左右时间联动

## S3-C 业务差异化功能（P2，1 个会话）

**范围**：温度语义标签 + 量价背离 + 板块对比增强 + 分量贡献度排序

### 1. 温度语义标签全页统一
- 所有出现温度的地方（卡片/tooltip/曲线轴标签）附带定性文字
- 颜色映射：极冷=深蓝底 / 偏冷=浅蓝底 / 中性=灰底 / 偏热=浅红底 / 极热=深红底

### 2. 量价背离标记
- 逻辑：当日涨跌幅 >0 但温度较昨日下降 ≥5 → 标记「顶背离」（菱形▽）
- 当日涨跌幅 <0 但温度较昨日上升 ≥5 → 标记「底背离」（菱形△）
- 热力图 cell 加 ECharts markPoint；tooltip 标注文字

### 3. 板块对比增强
- 现有 ≤5 板块对比基础上，右侧分量图增加「分量差异表」：
  对比选中板块的核心分量差值（如 RSI 差、量能差），量化分歧点

### 4. 分量贡献度排序
- 右侧分量明细按当日 |贡献| 排序（分量分×权重），前 3 名标注「主驱动」
- 数据源：D.comp（components JSON 已含分位分，需乘以权重）

**验收**：背离标记在极端日可见（如 2024-10-08 狂热日）；分量按贡献排序；语义标签全页统一

## S3-D 视觉规范统一（半天）

**范围**：设计语言统一、降噪、栅格规范化

### 1. 色彩规范
- 统一冷暖色系值：正温 #e34948 / 负温 #2a78d6 / 中性 #898781
- 所有模块使用同一套 CSS 变量（已有 dataviz 色板，确保一致性）

### 2. 栅格与间距
- 页面 12 栅格：热力图 8 格 / 分量图 4 格（2:1）
- 模块间距统一 16px；卡片内边距 12px
- 字体层级：数值 > 标签 > 辅助信息（3 级）

### 3. 降噪
- 热力图取消 cell 细边框（仅 hover 高亮描边）
- 移除多余分割线，用留白区分模块
- 图例字号统一 10px

**验收**：全页色值一致；间距统一；无多余边框
