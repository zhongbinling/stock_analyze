# 第二阶段开发计划 · 板块温度计

> 状态：**草案（待确认后分阶段实施）** · 日期：2026-10-15
> 前置：第一阶段 v1.0.0（大盘情绪体系与管理系统已交付）
> 目标：把"大盘情绪温度计"的方法论下沉到**行业板块级**——每个板块一个 -100~+100 的热度温度计，并作为新视图类型纳入现有管理/发布/展示体系。

---

## 0. 目标与定位

| 项 | 说明 |
|---|---|
| 输入 | A 股行业板块清单 + 各板块日频数据（行情/涨跌结构/涨停归属） |
| 输出 | ① 每板块纵向温度（自身历史分位，-100~100）② 横向热度（当日在全部板块中的百分位排名）③ 板块温度视图（热力图/列表/单板块详情） |
| 复用 | 评分方法论（滚动分位+加权+EMA）、em_api 多源客户端、任务系统（jobs）、生成规则（view_defs）、发布链、/mkt 展示 |
| 不做（本阶段） | 盘中实时、个股级评分、概念板块（预留开关）、申万付费数据 |

## 1. 板块体系与数据源

### 1.1 板块分类选择

| 候选 | 数量 | 优劣 | 决策 |
|---|---|---|---|
| **东财行业板块（BK 系）** | ~86 | 免费、接口与现有 em_api 同族（clist/push2his）、板块K线历史长、THS 涨停池的 `hybk` 行业名可映射 | ✅ 主口径 |
| 东财概念板块 | 400+ | 免费、轮动快但噪音大 | 预留 `type=concept` 开关，S8 可选 |
| 申万一级/二级 | 31/134 | 机构标准口径，完整历史数据需付费 | 预留映射表位，不阻塞 |

> 名称映射：THS `hybk`（如"医药商业"）与东财板块名（如"医药商业"）绝大多数同名直连；少数不一致建 `sector_alias` 别名表人工补齐，采集时打印未匹配项。

### 1.2 数据源与接口（全部复用 em_api 基础设施）

| 数据 | 接口 | 频率 | 历史深度 |
|---|---|---|---|
| 板块清单 | 东财 clist `fs=m:90+t:2`（行业）/`t:3`（概念）→ 90.BKxxxx | 周更 | — |
| 板块指数日线 | push2his `secid=90.BKxxxx`（与指数K线同接口，含成交额） | 每日 | 多年（与指数一致） |
| 板块涨跌家数 | 板块 clist 快照字段（涨/跌家数），随板块清单日更落库 | 每日 | **从采集日起积累**（免费源无历史） |
| 板块涨停结构 | **THS 涨停池 `hybk` 行业字段**（现有 zt 池已返回但未存储）→ 按行业聚合成板块级 涨停数/跌停数/连板高度/炸板 | 每日（随现有更新链） | 约一年滚动（同 THS 池） |
| 板块资金流（可选） | 东财资金流历史接口 | 每日 | 仅约最近100日 → S8 决定是否入模 |

采集成本评估：~86 板块 × 日线 1 次/板块，限速 0.3s ≈ **30~40 秒/日**，并入现有 update 任务链（fetch_daily 扩展，断点续跑同样适用）。

### 1.3 口径与边界

- 板块温度 = **板块自身纵向** + **全市场横向**双视角；纵向与大盘情绪完全同构（可比性强），横向解决"牛市里谁最热"的轮动问题
- 涨停结构分量使用 THS 口径（不含 ST/科创）→ 与大盘情绪一致，历史约一年；板块日线分量历史长
- 板块新增/退市：清单周更自动同步；新板块前 60 日不出温度（窗口不足，同大盘池分量规则）

## 2. 数据底座（sentiment.db 新表）

```sql
sectors(                 -- 板块字典
  code TEXT PRIMARY KEY, -- BKxxxx
  name TEXT, kind TEXT,  -- industry | concept(reserved)
  enabled INTEGER DEFAULT 1,
  first_date TEXT, last_date TEXT, updated_at TEXT)

sector_daily(            -- 板块日行情
  code TEXT, date TEXT,
  open REAL, close REAL, high REAL, low REAL,

  date TEXT, code TEXT,
  zt_count INTEGER, dt_count INTEGER,
  lb_max INTEGER, lb2_count INTEGER, zb_rate REAL,
  PRIMARY KEY(date, code))
  -- 来源改造: fetch_daily 在写 mood_raw 的同时按 hybk 聚合写入本表

sector_scores(           -- 温度结果(重算整表重建, 同 sentiment 表)
  date TEXT, code TEXT,
  score REAL,            -- 纵向温度 -100~100
  rank_pct REAL,         -- 横向热度: 当日温度在全部有效板块中的百分位 0~100
  stage TEXT, components TEXT,  -- JSON分量明细
  PRIMARY KEY(date, code))

```

## 3. 温度计模型设计

### 3.1 纵向温度（复用大盘方法论，逐板块独立计算）

每板块分量 → 250 日滚动分位 → 中心化 ±100 → 加权 → EMA(3) → 限幅。缺数据的分量当日权重自动归一化重分配（同大盘规则）。

| 分量组 | 分量（板块级） | 权重 |
|---|---|---|
| 动量 26% | RSI(14)分位 10 · 当日涨幅分位 8 · 跳空缺口 4 · K线实体 4 | 由板块日线计算 |
| 量能 20% | 板块成交额分位×方向(**非对称**, 与 V2.1 同口径) 12 · 量比趋势 8 | 板块日线 |
| 位置 20% | 20日乖离 8 · 60日乖离 5 · 250日位置 7 | 板块日线 |
| 波动 12% | 振幅分位×当日方向 12 | 板块日线 |
| 涨停结构 22% | 板块涨停家数分位 10 · 板块涨停占全市场比重分位 6 · 板块涨跌家数比分位 6 | pool_stat + up/down |

> 待确认项 A：权重初值如上（方法论对齐大盘：动量+量能+位置+波动=78% 同构，涨停结构 22% 替代大盘的接力率组）。锚定回测后再调。

### 3.2 横向热度（当日横截面）

`rank_pct` = 该板块当日纵向温度在全部有效板块中的百分位（0~100）。
用途：热度排名榜/热力图着色（一眼看出当日最强/最弱方向）；**不参与纵向温度计算**（避免反馈耦合）。

### 3.3 校准锚定（S6 验收核心）

- 2024-09-30/10-08：券商/半导体/软件等应 ≥ +80；全市场 rank_pct 分布合理
- 2024-02-05 微盘危机：微盘相关板块（软件/传媒等小票集中行业）应深度为负
- 历史领涨主线回放：任选 2~3 段主线行情（如某波 AI 行情），对应板块温度应持续高位
- 横向有效性：rank_pct 前 10 板块的次日/5日平均涨幅 > 后 10 板块（信息系数抽检）

## 5. 阶段拆分与验收

### S5 板块数据底座（1 个会话）
- sectors/sector_daily/sector_pool_stat/sector_alias 建表；em_api 扩展板块清单+板块K线接口（复用限速/重试/回退）
- fetch_daily：板块清单周更、全板块日线日更、THS 池 hybk 聚合落盘（含未匹配行业名告警）
- 数据管理页新增板块数据集组与缺失告警；首次全量回补（多年日线 ≈ 86×多次分页，预计 15~30 分钟，断点续跑）
- **验收**：≥80 个行业板块入库；抽样 3 个板块日线与东财网页一致；涨停聚合对账（某日全行业 zt 合计≈全市场zt）；未匹配行业名清单为空或已别名

### S6 温度引擎（1 个会话）
- sector_scores 计算引擎（core/sector.py：纵向温度 + 横向 rank_pct，复用 pct_pos/EMA 工具）
- CLI：`python core/sector.py calc|report [--code BKxxxx] [--top 10]`；锚定回放报告
- **验收**：§3.3 四项锚定全部通过；单板块计算耗时 < 5ms×86 板块（整表 <1s）

### S7 视图与管理集成（1 个会话）
- viewer 新增 sector_heat 类型（热力图+排名+单板块详情+大盘对照；沿用自包含 HTML/ECharts 与昼夜主题规范）
- view_defs 支持 type=sector_heat 规则 CRUD/立即生成/定时（17:00 链自动包含）；/mkt Tab 接入
- **验收**：产线规则生成→自动发布→匿名 /mkt 切 Tab 可见；热力图 ≥80 板块无卡顿（首屏 <1.5s）；点击板块出分量明细

### S8 增强（可选，按需排期）
- 板块资金流分量（东财资金流历史，仅近100日 → 作为短窗分量）
- 概念板块开关（kind=concept，复用全部管道）
- 板块温度历史回放视图 / 与 tdx 涨停生态选股公式联动
