# A股市场情绪评分系统 V2

基于自研东财/腾讯接口直连客户端 + SQLite 的完整版情绪评分: 在 V1 通达信量价版基础上,
加入涨停家数/跌停家数/炸板率/连板高度/昨日涨停表现等短线情绪分量。

> 不走 akshare 主链路的原因: 其请求不带浏览器 UA 且 clist 映射接口在本机网络下
> 被东财 WAF 断连; 本项目 em_api.py 直连底层接口(自带 UA/重试/多源回退), 更稳更轻。
> akshare 仅作为"当日涨跌家数"的可选依赖。

## 快速开始

```bash
cd v2
pip install -r requirements.txt

# ★ 推荐: 管理台(状态一览 + 一键更新 + 权重设置 + 视图发布)
python admin.py --open       # http://127.0.0.1:8501
```

管理台之外，各命令也可单独使用：

```bash
# 1) 采集数据(首次回补约240交易日, 需8~12分钟, 支持断点续跑)
python fetch_daily.py

# 2) 计算并查看最新情绪报告
python report.py

# 3) 交互式行情图查看器(自包含HTML, 双击即可打开, 可离线/分发)
python viewer.py --open            # 全历史
python viewer.py --years 2         # 近两年, 文件更小

# 4) 静态历史曲线图(matplotlib)
python report.py --chart --years 3

# 5) 校验(锚点日/IC/分位组)
python backtest.py
```

## 日常使用(每个收盘后跑一次)

```bash
python fetch_daily.py --start <最近一次抓取日YYYYMMDD>
python report.py
```

## 文件说明

| 文件 | 职责 |
|---|---|
| admin.py | **本地管理台**(http://127.0.0.1:8501): 数据状态/一键增量更新/权重设置/视图发布到 out/publish/ |
| config.yaml | 指数代码 / 回补起始 / 分量权重 / 窗口 / 阈值 |
| config_override.yaml | 管理台"保存为默认"生成的覆盖文件(优先级更高, 删除即恢复) |
| em_api.py | 东财+腾讯接口直连客户端(K线多源回退, 涨停四池) |
| db.py | SQLite 表结构(index_daily / mood_raw / sentiment) |
| fetch_daily.py | 指数日线 + 四池聚合统计 + 当日涨跌家数采集 |
| metrics.py | 宽表组装与派生指标(RSI/乖离/量比/振幅等) |
| score.py | 分位标准化 → 加权合成(缺失自动归一化) → EMA3 → 限幅 → 分档 |
| report.py | 文本日报 + 静态曲线图(out/sentiment_history.png) |
| viewer.py | **交互式行情图**(out/sentiment_viewer.html): K线/成交量/情绪分/涨跌停/炸板率接力率 五联面板, 十字光标悬停, 右侧面板联动显示当日全部构成指标(原始值/分位分/权重/贡献), 滚轮缩放+区间滑块 |
| backtest.py | 锚点日回放 / IC / 五分组单调性校验 |

## 评分口径(V2.1 结构, 与通达信 QXXF_情绪分V2.1 同构)

量能20%(非对称方向化: 放量×方向, 缩量恒负/涨减半) + 动量28%(RSI分位/涨幅/跳空/K线实体)
+ 位置20%(20日/60日乖离/N日位置) + 波动12%(振幅×方向);
通达信版中的"广度20%"(两市涨跌家数)历史无免费数据源, 由涨停结构组替代(涨停/跌停/炸板率/连板/接力率 各4%)。

## 数据口径与限制

- **涨停池口径**: 主源同花顺涨停复盘(沪深主板+创业板+科创板), 历史约一年滚动,
  当前可得起点 2025-10-15(config `pool_start`); 东财涨停专题(不含ST/科创板,
  仅最近约一个月)作近月兜底, 其"昨日涨停今日表现"留作 V2.1 逐日增量。
- **接力率**: 因两家数据源都无"昨日涨停表现"的历史序列, 赚钱效应用
  接力率(今日2板+家数/昨日涨停家数)代理, 全历史可得。
- **指数K线**: 东财 push2his 优先(含成交额); 被限流时自动回退腾讯(仅成交量)。
  评分的量能分量统一用"两市成交量(手)", 跨源口径一致, 也与通达信 V1 公式用 VOL 一致。
- **防封**: 东财对密集请求会临时封 IP, 采集已内置 0.4s 间隔与温和重试;
  若仍频繁断连, 调大 config.yaml 的 fetch.sleep 后重跑(断点续传)。
- 池分量历史不足 250 日窗口, 用 `pool_min_periods=60` 提前生效;
  池数据开始前(2012~2025.10)的分数自动退化为量价口径(缺失分量归一化剔除)。
- 情绪分是温度计不是买卖信号。
