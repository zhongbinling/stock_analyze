{================================================================}
{ 情绪分V2.1 · 广度增强版  公式名建议: QXXF2                        }
{ 用途: 大盘情绪温度计, -100(极度冰点/恐慌) ~ +100(极度狂热)        }
{ 挂法: 日线副图, 推荐品种 880003平均股价(全A等权)                 }
{       挂999999上证也可运行(价格/量能退化为沪市口径, 广度仍两市)   }
{ 升级: V1的7分量 → V2的12分量                                     }
{  ①两市涨跌家数净宽度 15% + 广度动量 5%  (跨品种引用, 新增)        }
{  ②量价配合 12% + 量能趋势配合 8% (V2.1方向化)                    }
{  ③跳空缺口(竞价/隔夜情绪) 5% (新增)                              }
{  ④K线实体强度 5% (新增)   ⑤60日乖离 5% (新增)                    }
{  ⑥RSI 10%(V2.1改分位) 当日涨幅 8% 20日乖离 8% N日位置 7%         }
{  ⑦振幅x方向 12%                                                  }
{  价格轴用880003等权平均股价, 修复上证权重护盘失真(2024-02-05类)   }
{----------------------------------------------------------------}
{ V2.1 修复"下跌负反馈钝化"(原V2恐慌日约-38即极限, 到不了冰点区):   }
{  原因1 量能两分量不带方向: 放量下跌=恐慌抛售, 但量能分位记正分,   }
{        与价格分量反向对冲(20%权重, 拉高约13分) -> 方向化修复      }
{  原因2 RSI线性变换有隐性下限: 指数RSI跌到25-35即罕见,             }
{        (RSI-50)*2最低约-50 -> 改分位化, 与其余分量统一口径        }
{  预期: 千股跌停级恐慌日 -38 → 约-65; 阴跌日读数基本不变;          }
{        上涨日读数不受影响(放量涨两版都记正分)                     }
{----------------------------------------------------------------}
{ 依赖: 首次使用请做一次 系统→盘后数据下载(日线),                   }
{       否则涨跌家数历史缺失, 广度分量不显示                        }
{       若跨品种引用报错(老版本), 见文末备用方案                    }
{ 调参: N=250(一年,标准) / 120(半年,更敏感) / 500(两年,更平滑)     }
{ 注意: 盘中分数随当日行情实时跳动, 收盘后定稿                      }
{================================================================}
N:=250;
EPS:=0.000001;

{— 公共: 前收/涨跌幅/方向 —}
LC:=REF(CLOSE,1);
CHG:=(CLOSE/LC-1)*100;
DIR:=IF(CHG>=0,1,-1);

{— 1. 市场广度: 两市涨跌家数净宽度 (15%) —}
{净宽度=(涨-跌)/(涨+跌), 综合反映涨跌家数比与涨幅分布宽度}
{跨品种引用上证+深证成指的上涨/下跌家数, 挂任意品种均可用}
UPA:="SH999999$ADVANCE"+"SZ399001$ADVANCE";
DNA:="SH999999$DECLINE"+"SZ399001$DECLINE";
BRD:=UPA+DNA;
BR:=IF(BRD>0,(UPA-DNA)/(BRD+EPS),0);
S1:=(BR-LLV(BR,N))/(HHV(BR,N)-LLV(BR,N)+EPS)*200-100;

{— 2. 广度动量: 净宽度5/20日均值差 (5%) —}
{宽度加速上行=普涨扩散, 加速下行=普跌蔓延}
BRM:=MA(BR,5)-MA(BR,20);
S2:=(BRM-LLV(BRM,N))/(HHV(BRM,N)-LLV(BRM,N)+EPS)*200-100;

{— 3. 量价配合: 放量方向 (12%) V2.1方向化 —}
{放量涨=狂热加分, 放量跌=恐慌减分(修复原版反向加分),}
{缩量跌=退潮减分, 缩量涨=反弹乏力减半计}
{挂880003时AMOUNT=全A成交额; 挂999999想用两市口径,}
{改为: AMT:=AMOUNT+"SZ399106$AMOUNT"; (399106深证综指=全深市,}
{勿用399001深证成指-成分口径)}
AMT:=AMOUNT;
VP:=(AMT-LLV(AMT,N))/(HHV(AMT,N)-LLV(AMT,N)+EPS)*200-100;
S3:=IF(VP>0,VP*DIR,IF(CHG>=0,VP*0.5,VP));

{— 4. 量能趋势配合: 5/20日均额比 (8%) V2.1方向化 —}
VRA:=MA(AMT,5)/(MA(AMT,20)+EPS);
VRP:=(VRA-LLV(VRA,N))/(HHV(VRA,N)-LLV(VRA,N)+EPS)*200-100;
S4:=IF(VRP>0,VRP*DIR,IF(CHG>=0,VRP*0.5,VRP));

{— 5. 动量: 14日RSI 分位 (10%) V2.1改分位 —}
{原线性(RSI-50)*2在指数上有约-50隐性下限, 下跌响应钝;}
{分位化后RSI创一年新低即记满分负值, 与其余分量口径统一}
R14:=SMA(MAX(CLOSE-LC,0),14,1)/(SMA(ABS(CLOSE-LC),14,1)+EPS)*100;
S5:=(R14-LLV(R14,N))/(HHV(R14,N)-LLV(R14,N)+EPS)*200-100;

{— 6. 当日涨跌幅 分位 (8%) —}
S6:=(CHG-LLV(CHG,N))/(HHV(CHG,N)-LLV(CHG,N)+EPS)*200-100;

{— 7. 跳空缺口: 隔夜/竞价情绪 (5%) —}
{高开幅度分位: 竞价抢筹则高, 恐慌出逃则低}
GAP:=(OPEN/LC-1)*100;
S7:=(GAP-LLV(GAP,N))/(HHV(GAP,N)-LLV(GAP,N)+EPS)*200-100;

{— 8. K线强度: 实体占比MA3 (5%) —}
{(收-开)/(高-低), 带方向的当日多空力度, 含上下影线信息}
KRB:=MA((CLOSE-OPEN)/(HIGH-LOW+EPS),3);
S8:=(KRB-LLV(KRB,N))/(HHV(KRB,N)-LLV(KRB,N)+EPS)*200-100;

{— 9. 20日乖离率 分位 (8%) —}
B20:=(CLOSE-MA(CLOSE,20))/MA(CLOSE,20)*100;
S9:=(B20-LLV(B20,N))/(HHV(B20,N)-LLV(B20,N)+EPS)*200-100;

{— 10. 60日乖离率 分位 (5%) —}
{慢趋势轴, 与20日乖离形成快慢组合}
B60:=(CLOSE-MA(CLOSE,60))/MA(CLOSE,60)*100;
S10:=(B60-LLV(B60,N))/(HHV(B60,N)-LLV(B60,N)+EPS)*200-100;

{— 11. N日价格位置 (7%) —}
S11:=(CLOSE-LLV(CLOSE,N))/(HHV(CLOSE,N)-LLV(CLOSE,N)+EPS)*200-100;

{— 12. 波动放大×方向 (12%) —}
{高振幅出现在情绪两极, 用当日涨跌方向区分狂热/恐慌}
AMP:=(HIGH-LOW)/(LC+EPS)*100;
AP:=(AMP-LLV(AMP,N))/(HHV(AMP,N)-LLV(AMP,N)+EPS)*200-100;
S12:=AP*IF(CHG>=0,1,-1);

{— 加权合成 + 平滑 + 限幅 (权重和=1.00) —}
{广度20% 量能20% 动量28% 位置20% 波动12%}
RAW:=S1*0.15+S2*0.05+S3*0.12+S4*0.08+S5*0.10+S6*0.08+S7*0.05+S8*0.05+S9*0.08+S10*0.05+S11*0.07+S12*0.12;
OK:=BARSCOUNT(CLOSE)>N+30;
SCORE:=IF(OK,MAX(-100,MIN(100,EMA(RAW,3))),DRAWNULL);

{— 绘制: 红绿柱 + 参考线 + 黄色主线 + 情绪周期信号 —}
STICKLINE(SCORE>=0,0,SCORE,0.8,0),COLORRED;
STICKLINE(SCORE<0,0,SCORE,0.8,0),COLORGREEN;
狂热:80,COLORGRAY;
高热:60,COLORGRAY;
恐慌:-60,COLORGRAY;
冰点:-80,COLORGRAY;
情绪分:SCORE,COLORYELLOW,LINETHICK2;
DRAWTEXT(OK AND CROSS(SCORE,60),72,'狂热'),COLORRED;
DRAWTEXT(OK AND CROSS(60,SCORE),72,'退潮'),COLORYELLOW;
DRAWTEXT(OK AND CROSS(-60,SCORE),-72,'冰点'),COLORGREEN;
DRAWTEXT(OK AND CROSS(SCORE,-60),-72,'修复'),COLORWHITE;
