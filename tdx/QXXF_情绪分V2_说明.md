## 0. 一页速览：V1 → V2 变了什么

| | V1（QXXF） | V2（QXXF2） |
|---|---|---|
| 分量数 | 7（纯单指数量价） | **12**（新增广度 2 + 竞价/K线/慢趋势 3，量能升级） |
| 广度数据 | ❌ 无 | ✅ **两市涨跌家数**（跨品种引用 `"SH999999$ADVANCE"+"SZ399001$ADVANCE"`） |
| 量能口径 | VOL 成交量（股数） | **AMOUNT 成交额**（金额，跨时期跨股票可比） |
| 价格轴 | 上证指数（加权，护盘失真） | **880003 平均股价（全A等权）** |
| 已知缺陷修复 | — | ①"指数护盘、个股惨烈"低估恐慌（2024-02-05 类）→ 广度分量 + 等权轴双修复；②量价单因子失真 → 广度交叉验证 |
| 仍做不到 | 涨停家数/炸板率/连板高度等横截面统计（公式语言限制） | 同左 → 配套选股公式（人工/半自动）或 Python v2 |

**核心结论**：通达信公式拿不到涨停池级横截面数据（这是公式语言能力边界，与版本无关），但**涨跌家数广度可以拿到**——V2 把最容易、价值最高的"广度"因子补进来了，这是对"护盘分化行情"失真的最大修复。

## 1.5 V2.1：下跌负反馈钝化的诊断与修复（2026-10-14）

**现象**：上涨反馈快（924 行情轻松冲高分区），下跌时近年分数到 -40 附近即极限、波动不明显。

**分量级复盘（恐慌日，如 2024-02-05 型）**：

| 分量 | 恐慌日读数 | 诊断 |
|---|---|---|
| 广度 S1/S2、跳空 S7、实体 S8、振幅×方向 S12 | -70~-90 | 正常反馈 |
| 量能 S3、量比 S4（合计 20% 权重） | **各 +60~+80，反向拉高约 +13 分** | ❌ 主因：量能不带方向，放量下跌=高活跃度→记正分 |
| RSI S5 | ≈ -35 | ❌ 次因：指数 RSI 跌到 25-35 即罕见，线性 (RSI-50)×2 有约 -50 的隐性下限 |
| 60日乖离 S10、N日位置 S11 | 0~-40 | 慢因子托底（设计如此，提供情绪惯性） |

旧版恐慌日合计 RAW ≈ **-38**，与"-40 到极限"的观察吻合；上涨时量价同向共振（放量涨→量能、价格全加分），故能到 +80。**根本原因：量能 20% 权重只在上涨时与情绪同向。**

**修复（两处，权重不动）**：

1. **量能两分量方向化（量价配合）**：

| 量价组合 | V2 读数 | V2.1 读数 | 语义 |
|---|---|---|---|
| 放量涨 | + | + | 狂热（不变） |
| 放量跌 | +70 ❌ | **-70 ✅** | 恐慌抛售（核心修复） |
| 缩量跌 | -45 | -45 | 阴跌退潮（不变） |
| 缩量涨 | -40 | -20 | 缩量反弹、修复乏力（减半计） |

2. **RSI 改分位化**：与其余 11 分量统一口径，消除线性隐性下限；RSI 创一年新低即记满分负值。

**预期效果**：千股跌停级恐慌日 -38 → **约 -65~-70**（可触发冰点线）；缩量阴跌日读数基本不变（-31 → -30）；上涨日不受影响（放量涨两版都记正分）。

**已知残留**：① 方向用单日 CHG 判定，"放量滞涨/十字星" granularity 有限（与 V1 振幅分量同一局限）；② 慢因子（60日乖离、N日位置）在急跌初期仍会托底——这是"情绪有惯性"的设计意图，若想更快可把 N 调到 120；③ 分位化的固有特性：窗口内（250日）没有出现过极端下跌事件时，普通大跌日分位上不去——这是"相对一年"的语义，非 bug；真正需要绝对口径时用 Python v2 的跌停家数分量补。

## 2. 需求因子可行性矩阵（你列的 11 项 → 落地方式）

| 需求因子 | 通达信公式内 | 落地方式 |
|---|---|---|
| 涨跌家数比 | ✅ | **QXXF2 分量1/2**：跨品种引用 `"SH999999$ADVANCE"+"SZ399001$ADVANCE"` / `$DECLINE`（多源社区验证的官方语法；仅指数有效，故从任意品种图表引用指数） |
| 涨幅分布（宽度） | ⚠️ 代理 | 净宽度 + 广度动量即分布宽度的指数级代理；**逐股分布（如涨>5%家数）公式不可得** → Python v2 |
| 成交量变化 | ✅ | **QXXF2 分量3/4**：成交额分位 + 均额比（升级为金额口径；挂 880003 = 全A，比 V1 的沪市 VOL 更代表全市场） |
| 大盘指数位置 | ✅ | **QXXF2 分量9/10/11**：20日/60日乖离 + N日位置，且价格轴换成等权平均股价 |
| 换手率 | ⚠️ 不采用 | 指数级"换手率"无流通股本分母（CAPITAL 对指数无意义）；市场级换手 ≈ 成交额分位，已由分量3覆盖 |
| 涨停家数/跌停家数 | ❌ 公式内 | 横截面统计，公式语言无此能力 → ①配套选股公式建 ZT/DT 板块读家数（半自动）；②Python v2（东财涨停池，精确+历史） |
| 炸板率 | ❌ 公式内 | 同上 → 配套选股 ZB 板块，炸板率 = ZB家数/(ZT家数+ZB家数) 手工算 |
| 连板高度 | ❌ 公式内 | 同上 → 配套选股 LB 系列（K=8,7,6... 递减跑，最高命中即高度） |
| 昨日涨停今日表现 | ❌ 公式内 | ①建 YZT 板块看板块指数涨跌幅，或挂 QXXF2 看赚钱效应温度；②若本地有"昨日涨停指数"（88086x~88088x 区段，版本而异，键盘精灵搜确认）可直接看 |
| 北向资金 | ❌ 排除 | 2024-08 起交易所停止盘中实时披露（仅盘后成交总额），实时分量无数据源，且公式无法引用 → 保持排除（方案文档既定结论） |
| 融资融券 | ❌ 公式内 | 余额 T+1 每日一次、公式不可引用；作为慢变量对短线情绪贡献有限 → Python v2 可选扩展（akshare 沪深两融接口） |

## 3. 安装与首次配置

1. **建公式**：`Ctrl+F` → 技术指标 → 其它类型 → 新建 → 名称 `QXXF2` → 粘贴 [QXXF_情绪分V2.txt](QXXF_情绪分V2.txt) → 测试公式 → 确认。
2. **首次数据准备（重要）**：`系统 → 盘后数据下载`，勾选日线（沪深），下载一次。涨跌家数（ADVANCE/DECLINE）的历史序列依赖全市场本地日线，不下载则广度分量历史缺失（当日盘中仍是实时的）。
3. **挂图**：键盘精灵输入 `880003`（平均股价）→ 日线 → 副图输入 `QXXF2`。**推荐 880003**：全A等权、AMOUNT=全A成交额，且对"权重护盘"免疫。
4. **兼容**：挂 `999999` 上证指数也能跑（广度仍为两市），但价格/量能退化为沪市加权口径——此时建议把公式里 `AMT:=AMOUNT;` 一行改为 `AMT:=AMOUNT+"SZ399106$AMOUNT";`（深证综指=全深市口径，与 v2/config.yaml 的 secondary 一致；**勿用 399001 深证成指，它是成分指数**）。
5. **报错处理**：若"测试公式"在跨品种引用两行报错（老版本不支持），按文件末尾备用方案 A 改为 `UPA:=ADVANCE; DNA:=DECLINE;`（挂 880003/大盘时有效）。
6. **乱码**：同 V1，粘贴乱码则记事本另存为 ANSI 再复制。

盘中实时性：涨跌家数、成交额、价格均随行情快照实时更新，情绪分盘中跳动、收盘定稿——与 V1 一致。

## 5. 权重设计与校准

- TDX V2 = Python v2 的"量价+广度"子集：`v2/config.yaml` 的 `v1_weights` 可更新为本表 12 分量权重，用于两版互验（建议由 v2 的 backtest.py 跑完锚点日回放后再定稿）。
- 校准锚点：整体方案 §2.5 的锚点日表中，**2024-02-05（千股跌停、上证护盘）在 QXXF2 下应明显低于 V1**（等权价格轴 + 广度分量的作用）——这是检验 V2 升级是否生效的关键测试日；2024-09-30~10-08 应 ≥ +80。
- 调参入口：`N`（分位窗口）与 RAW 行内权重（保持和=1.00）。

## 6. 已知限制与口径

1. **广度口径 = 沪深两市**（引用 999999+399001），不含北交所（约 250 家，对全市场宽度影响 <5%）。
2. 早期历史若本地未下载足够年限的全市场日线，对应时段广度分量失真（BR 被 0 值中性化，分数退化为量价版）。
3. ADVANCE/DECLINE 为指数专属函数：跨品种引用时以指数为数据源没问题；备用方案 A 里直接调用时，挂个股无效。
4. 停牌/新股导致 880003 成分变化、成交额自然膨胀（注册制后股票数增长）——分位标准化天然消化大部分，但超长期（>3年）回看时量能分位会系统性偏高，属已知口径问题（Python v2 可用"成交额/流通市值"修正）。
5. 涨停判定的板块比例分支（配套选股公式）未覆盖新股上市首日（无涨跌幅限制），极少数误判；精确口径以交易所披露/东财涨停池为准。
