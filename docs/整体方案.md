# A股市场情绪评分系统 · 整体方案

| 项目 | 内容 |
|---|---|
| 目标 | 输出 A 股市场情绪分值 **-100 ~ +100**（-100 极度冰点/恐慌，+100 极度狂热），支持历史回看与盘中实时 |
| 当前阶段 | **V1 通达信公式基础版**（本方案已附带完整公式代码，当天即可使用） |
| 文档日期 | 2026-10-11 |
| 配套文件 | [tdx/QXXF_情绪分V1.txt](../tdx/QXXF_情绪分V1.txt) — 可直接粘贴进通达信的公式代码 |

---

## 0. 一页速览

**做什么**：一个"市场温度计"——每天（及盘中）给出一个 -100~+100 的情绪分，用于判断市场处于情绪周期的哪个位置（冰点→修复→发酵→高潮→退潮）。

**怎么分层做**：

| 版本 | 形态 | 核心数据 | 状态 |
|---|---|---|---|
| **V1** | 通达信技术指标公式（副图） | 单一指数的 OHLCV（量价） | ✅ 本方案交付，10 分钟可用 |
| **V1.5** | 通达信增强公式 QXXF2 + 配套选股 | 单指数量价 + **两市涨跌家数广度**（跨品种引用）+ 成交额/竞价/K线因子 | ✅ 广度公式已交付（2026-10-11，tdx/QXXF_情绪分V2.txt） |
| **V2** | Python 程序（akshare/pytdx + SQLite） | 涨停池/炸板池/涨跌家数/成交额/融资余额等全维度 | 2~4 周 |
| **V3** | Python 实时监控 + 推送 + 看板 | 盘中分钟级数据 + 阈值告警 | 展望 |

**为什么这样分层**：通达信公式系统拿不到涨停家数、炸板率等横截面统计（公式语言能力边界，与版本无关），但**涨跌家数广度可以跨品种引用**（2026-10-11 已确认语法并落地到 V1.5/QXXF2）；真正的短线情绪核心数据（涨停/炸板/连板）仍放到 V2 用 Python 解决。

## 1. 评分定义与使用哲学

### 1.1 分档语义

| 区间 | 状态 | 情绪周期 | 典型含义 |
|---|---|---|---|
| [-100, -80] | 极度冰点 | 冰点期 | 恐慌极致，历史级大底区域，统计上反弹赔率最高 |
| (-80, -60] | 冰点/恐慌 | 冰点期 | 跌停潮、缩量阴跌或放量急跌 |
| (-60, -30] | 偏冷/退潮 | 退潮期 | 赚钱效应消失，资金离场 |
| (-30, -10] | 中性偏弱 | — | 温水市 |
| (-10, +10] | 中性 | — | 多空平衡 |
| (+10, +30] | 中性偏强 | 修复期 | 赚钱效应萌芽 |
| (+30, +60] | 偏热/发酵 | 发酵期 | 放量上涨、热点轮动 |
| (+60, +80] | 狂热/高潮 | 高潮期 | 涨停潮、普涨、成交天量 |
| (+80, +100] | 极度狂热 | 高潮末期 | 统计上风险收益比最差，注意退潮 |

### 1.2 使用哲学（重要）

- 情绪分是**温度计，不是买卖信号**。极端区只代表统计意义上的赔率变化（冰点区买入胜率升高、狂热区追高赔率变差），不预测拐点时间。
- 标准用法是**逆向参考 + 周期定位**：分数进入冰点区开始分批关注，进入狂热区开始分批兑现；中间区域不构成依据。
- 分数会随当日行情**实时跳动，收盘定稿**；单日大幅摆动本身也是情绪不稳定的信号。

## 2. 情绪模型设计（核心，各版本通用）

### 2.1 设计原则

1. **多维正交**：量能、动量、位置、波动各自打分，避免单一指标失真。
2. **滚动分位标准化**：所有分量统一映射到 0~100，再中心化为 -100~+100。这样不同量纲（成交手数、百分比、家数）可以直接加权，且天然自适应市场状态变化。
3. **加权合成 → 轻度平滑 → 限幅**：EMA(3) 平滑消除单日噪声，输出限制在 [-100, 100]。
4. **可校准**：权重只是经验起点，V2 用历史数据回测校准。

### 2.2 标准化方法（通达信/Python 通用）

```
分位值 PCT(X, N) = (X - LLV(X,N)) / (HHV(X,N) - LLV(X,N)) × 100     → 0~100
中心化 S(X, N)   = PCT × 2 - 100                                    → -100~+100
```

- N 为回看窗口，默认 250 个交易日（约一年）。
- 含义：当前值在过去一年中的相对位置。放量到一年天量 → 量能分接近 +100；跌到一年新低 → 价格分接近 -100。

### 2.3 指标体系总表

六大维度、V1 使用其中 7 个分量；涨停/广度类分量从 V1.5/V2 起引入。

| 维度 | 分量 | 方向 | V1 权重 | 数据来源 |
|---|---|---|---|---|
| **赚钱效应** | 接力率 = 今日2板+家数/昨日涨停家数 | 正 | —（V1.5/V2） | 同花顺涨停复盘 |
| | 涨停家数（主板+创业板+科创板口径） | 正 | —（V1.5/V2） | 同花顺涨停复盘 |
| | 炸板率 = 炸板/(涨停+炸板) | 反 | —（V1.5/V2） | 同花顺(封板率换算) |
| | 连板高度、连板家数 | 正 | —（V2） | 同花顺涨停复盘 |
| | 跌停家数 | 反 | —（V1.5/V2） | 同花顺涨停复盘 |
| | 昨日涨停股今日平均涨幅 | 正 | —（V2.1 增量，仅东财近月可得） | 东财涨停专题 |
| **市场广度** | 上涨/下跌家数比 | 正 | —（V1.5/V2） | 全市场快照 |
| | 20 日新高/新低家数比 | 正 | —（V2） | 全市场日线 |
| **量能** | 成交量的 250 日分位 | 正 | 15% | 指数 VOL |
| | 5 日/20 日均量比分位 | 正 | 10% | 指数 VOL |
| **动量** | 14 日 RSI（0~100 → ×2-100） | 正 | 20% | 指数收盘价 |
| | 当日涨跌幅分位 | 正 | 15% | 指数收盘价 |
| **位置/趋势** | 20 日乖离率 BIAS 分位 | 正 | 15% | 指数收盘价 |
| | 250 日价格位置 | 正 | 10% | 指数收盘价 |
| **波动** | 日振幅分位 × 当日涨跌方向 | 放大器 | 15% | 指数 H/L/C |

> 说明：**波动分量**带方向——"放量大涨"记为热，"放量大跌"记为冷；高振幅本身出现在情绪两极，用方向区分。
> 位置/趋势类分量（BIAS、250 日位置）使分数略带趋势性，这是有意的：情绪本就有惯性。

> **2026-10-11 更新**：通达信版已升级为 **QXXF2（情绪分V2·广度增强版）**，分量 7→12：新增两市涨跌家数净宽度、广度动量、跳空缺口（竞价情绪）、K线实体强度、60日乖离，量能改成交额口径，价格轴换 880003 等权平均股价。因子可行性矩阵与安装说明见 [tdx/QXXF_情绪分V2_说明.md](../tdx/QXXF_情绪分V2_说明.md)。

### 2.4 合成公式

```
原始分 RAW = Σ 权重i × 分量i                    （各分量 ∈ [-100, +100]）
情绪分 SCORE = clamp( EMA(RAW, 3), -100, +100 )
```

### 2.5 校准方法（V2 执行，V1 用经验权重）

1. **极端日回放（锚点日）**：分数在下列日期应落在对应区间，否则调权重：

| 锚点日 | 期望分数 | 说明 |
|---|---|---|
| 2015-06-12（5178 顶部） | ≥ +70 | 杠杆牛顶 |
| 2015-08-24 / 2016-01-04 | ≤ -70 | 股灾/熔断 |
| 2018-12-24 附近 | ≤ -60 | 长熊尾部冰点 |
| 2024-02-05 | ≤ -80 | 微盘流动性危机、千股跌停（注：上证指数被权重护盘，**指数版 V1 会低估**，此锚点主要校准 V2 的广度/涨停分量） |
| 2024-09-30 ~ 10-08 | ≥ +80 | 政策行情，上证单日 +8% |
| 近一年自选 2~3 个极端日 | 人工标注 | 建议自行补充 2025~2026 年的顶底日 |

2. **信息系数检验**：各分量与"未来 5/10/20 日指数收益"算 Spearman IC，剔除长期无预测力的分量。
3. **分组单调性**：按分数十分位分组，检验未来收益是否单调（冰点组收益 > 狂热组）。
4. **权重寻优**：在分量 IC 基础上小范围网格搜索，防止过拟合（权重和恒为 1，单分量权重限制在 5%~30%）。

## 4. V1 通达信基础版（已交付）

### 4.1 定位与边界

- **定位**：挂在**上证指数（999999）日线副图**的市场温度计，纯量价驱动，收盘定稿、盘中实时跳动。
- **能做**：情绪周期定位（冰点/狂热识别）、历史任意时段回看、60 分钟等更短周期（窗口 N 变为 250 根该周期 K 线）。
- **不能做**（通达信公式环境限制）：拿不到涨停家数/涨跌家数等横截面数据 → 对"指数被护盘、个股惨烈"的分化行情会低估恐慌（如 2024-02-05）。此问题由 V1.5/V2 解决。

### 4.2 分量与权重

见 2.3 总表中标注 V1 权重的 7 个分量：RSI 20%、当日涨幅分位 15%、BIAS20 分位 15%、量能分位 15%、量比趋势 10%、250 日价格位置 10%、振幅×方向 15%。

### 4.3 公式代码

完整代码见 [tdx/QXXF_情绪分V1.txt](../tdx/QXXF_情绪分V1.txt)（同步附在下方）：

```text
{================================================================}
{ 情绪分V1 · 指数基础版  公式名建议: QXXF                          }
{ 用途: 大盘情绪温度计, -100(极度冰点/恐慌) ~ +100(极度狂热)        }
{ 挂法: 日线副图, 建议品种 999999上证指数(或880003平均股价)         }
{ 原理: 7个分量各自做N日滚动分位标准化后加权合成, EMA3平滑, 限幅    }
{ 调参: N=250(一年,标准) / 120(半年,更敏感) / 500(两年,更平滑)     }
{ 注意: 盘中分数随当日行情实时跳动, 收盘后定稿                      }
{================================================================}
N:=250;
EPS:=0.000001;

{— 1. 动量: 14日RSI (权重20%) —}
LC:=REF(CLOSE,1);
R14:=SMA(MAX(CLOSE-LC,0),14,1)/(SMA(ABS(CLOSE-LC),14,1)+EPS)*100;
S1:=(R14-50)*2;

{— 2. 当日涨跌幅 分位 (15%) —}
CHG:=(CLOSE/REF(CLOSE,1)-1)*100;
S2:=(CHG-LLV(CHG,N))/(HHV(CHG,N)-LLV(CHG,N)+EPS)*200-100;

{— 3. 20日乖离率 分位 (15%) —}
B20:=(CLOSE-MA(CLOSE,20))/MA(CLOSE,20)*100;
S3:=(B20-LLV(B20,N))/(HHV(B20,N)-LLV(B20,N)+EPS)*200-100;

{— 4. 量能水平 分位 (15%) —}
S4:=(VOL-LLV(VOL,N))/(HHV(VOL,N)-LLV(VOL,N)+EPS)*200-100;

{— 5. 量能趋势: 5/20日均量比 分位 (10%) —}
VR:=MA(VOL,5)/(MA(VOL,20)+EPS);
S5:=(VR-LLV(VR,N))/(HHV(VR,N)-LLV(VR,N)+EPS)*200-100;

{— 6. N日价格位置 (10%) —}
S6:=(CLOSE-LLV(CLOSE,N))/(HHV(CLOSE,N)-LLV(CLOSE,N)+EPS)*200-100;

{— 7. 波动放大×方向 (15%) —}
AMP:=(HIGH-LOW)/(REF(CLOSE,1)+EPS)*100;
AP:=(AMP-LLV(AMP,N))/(HHV(AMP,N)-LLV(AMP,N)+EPS)*200-100;
S7:=AP*IF(CHG>=0,1,-1);

{— 加权合成 + 平滑 + 限幅 —}
RAW:=S1*0.20+S2*0.15+S3*0.15+S4*0.15+S5*0.10+S6*0.10+S7*0.15;
OK:=BARSCOUNT(CLOSE)>N+30;
SCORE:=IF(OK,MAX(-100,MIN(100,EMA(RAW,3))),DRAWNULL);

{— 绘制: 红绿柱 + 参考线 + 黄色主线 + 情绪周期信号 —}
STICKLINE(SCORE>=0,0,SCORE,0.8,0),COLORRED;
STICKLINE(SCORE<0,0,SCORE,0.8,0),COLORGREEN;
狂热:80,COLORGRAY;
高热:60,COLORGRAY;
恐慌:-60,COLORGRAY;
冰点:-80,COLORGRAY;
情绪分:SCORE,COLORYELLOW,LINETHICK2;
DRAWTEXT(OK AND CROSS(SCORE,60),72,'狂热'),COLORRED;
DRAWTEXT(OK AND CROSS(60,SCORE),72,'退潮'),COLORYELLOW;
DRAWTEXT(OK AND CROSS(-60,SCORE),-72,'冰点'),COLORGREEN;
DRAWTEXT(OK AND CROSS(SCORE,-60),-72,'修复'),COLORWHITE;
```

### 4.4 安装与使用（3 步，约 10 分钟）

1. **新建公式**：打开通达信 → `Ctrl+F` 打开公式管理器 → 技术指标 → 其它类型 → 【新建】→ 公式名称填 `QXXF` → 打开 [tdx/QXXF_情绪分V1.txt](../tdx/QXXF_情绪分V1.txt) 全选复制、粘贴进代码区 → 点【测试公式】，通过后【确认】。
2. **挂到指数**：打开上证指数 `999999` 日线 → 在副图区域键盘输入 `QXXF` 回车（或副图右键 → 选择指标 → QXXF）。
3. **看盘**：黄色主线即情绪分；红柱=正值（热），绿柱=负值（冷）；出现"冰点/狂热/修复/退潮"文字即情绪周期切换点。

**盘中实时**：保持行情连接，日线最新一根 K 线的收盘价/成交量实时更新，情绪分随之跳动，收盘定稿。若想要盘中更细粒度，可切到 60 分钟周期（N=250 即回看约 60 个交易日）。

**调参**：副图右键 → 修改公式，改 `N` 或各分量权重（权重和保持 1.0）。

**乱码处理**：若粘贴后中文注释/文字乱码，用记事本打开 txt → 另存为 → 编码选 ANSI → 再复制粘贴。

### 4.5 已知局限

1. 无涨停/广度数据 → 分化行情（指数护盘、个股跌停潮）会**低估恐慌**。
2. 只反映单一指数（上证） → 建议同时在 880003 平均股价上挂一份对照。
3. 权重为经验值，未经回测校准。
4. 前 N+30 根 K 线因窗口不足不显示分数（新股/历史短的指数会大片空白）。

> 详见 [tdx/QXXF_情绪分V2_说明.md](../tdx/QXXF_情绪分V2_说明.md)；本章以下涨停专题人工判读方法仍适用（可与①②互验）。

通达信自带**涨停专题板块指数**（"涨停指数 / 昨日涨停指数 / 昨日连板指数 / 炸板指数"等，代码在 88086x~88088x 区段，**各版本代码不同，请在键盘精灵输入名称搜索确认**）。两种用法：

### 5.1 用法 A：把 QXXF 公式挂到板块指数上（零改动）

QXXF 是通用分位标准化框架，直接挂到"昨日涨停指数"日线上，得到的分数就是**赚钱效应温度**：分数高=昨日涨停股今天继续大涨（接力情绪亢奋），分数低=涨停股集体被核（亏钱效应）。

### 5.2 用法 B：盘面直接读数（每日 1 分钟例行）

打开通达信涨停专题（功能菜单/键盘精灵搜"涨停"），人工记录并按下表判读：

| 观察项 | 冰点 | 正常 | 亢奋 |
|---|---|---|---|
| 涨停家数 | <20 | 40~80 | >120 |
| 跌停家数 | >30 | <5 | 0 |
| 炸板率 | >40% | 20%~30% | <15% |
| 连板高度 | ≤2 | 3~4 | ≥5 |
| 昨日涨停指数今日涨幅 | <-3% | 0~2% | >3% |
| 上涨家数 | <800 | 2000± | >4000 |

### 5.3 进阶：自定义数据（可选，依赖版本）

较新版通达信支持"自定义数据/扩展数据"（公式管理器 → 数据管理），可把每日涨停家数、炸板率手工或脚本写入，公式中引用后即可与 QXXF 合成完整版。此路径配置繁琐，**建议直接跳 V2 用 Python 做**。

### 6.4 V2 实测结果（V2.1 结构对齐后，2026-10-14，数据 2012-05~2026-10-09）

**V2.1 对齐**（与用户通达信公式 [QXXF_情绪分V2.txt](../tdx/QXXF_情绪分V2.txt) 同构）：
RSI 线性→分位、量能非对称方向化（放量×方向、缩量恒负/涨减半）、新增跳空缺口/K线实体/60日乖离分量、
权重改为 量能20+动量28+位置20+波动12，涨停结构组 20% 替代其"广度组"（涨跌家数历史无源）。

- 锚点日回放 **8/8 方向全中**，恐慌深度显著修复：2024-02-05 **-61**（V1 量价版 -31）、
  2015-08-24 股灾 -39、2016-01-04 熔断 -31；2024-09-30/10-08 狂热 +81/+85。
- 对齐过程中发现并修复：对称翻转发在"缩量下跌"日错误翻正（如 2016 熔断半日市），采用通达信V2.1的非对称口径后恢复。
- IC（vs 未来5日收益）≈ **-0.047**（V2.1 后反向性增强）；五分组 Q1冰点 +0.35% > Q2 > Q3 > Q4 单调；
  Q5 仍偏高（长样本为量价口径、牛市动量短期延续所致，池数据满一年后重校）。

## 9. 风险与注意事项

1. **方法论**：情绪分非交易信号，极端区只改变赔率不保证拐点；避免过度拟合历史（权重寻优限制搜索空间）。
2. **口径**：涨停规则碎片化（主板 10%、创业板/科创板 20%、北交所 30%、ST 5%、新股首日无涨跌幅）——V2 统计时需按板块分口径或采用交易所"披露口径"。
3. **数据**：akshare 接口偶有变更（接口名以官方文档为准）；通达信板块指数代码因版本/数据商而异。
4. **失真场景**：V1 指数版在护盘分化行情低估恐慌（锚点 2024-02-05）；V2 需保留广度与涨停分量权重 ≥40% 以覆盖此场景。
5. **合规**：本系统仅做数据分析，不构成投资建议；对外展示需注意。
